# 다중 숫자 합성셋

MNIST 원본과 합성셋은 모두 프로젝트의 **`data/` 아래**에 보관한다. `data/`는 Git 추적 제외 대상이다. 새 작업 폴더에서 원본이 없으면 공식 MNIST를 다시 다운로드하며, 기존 모델의 재학습은 필요 없다.

## 두 단계의 구분

| 단계 | 구분 | 데이터·역할 |
|---|---|---|
| 단일 숫자 CNN | train | 55,000장으로 가중치 학습 |
| 단일 숫자 CNN | val | 5,000장으로 학습 설정·가중치 선택 |
| 단일 숫자 CNN | test | 공식 10,000장으로 CNN 단독 평가 |
| 다중 숫자 판독 | val · `tuning` | 단일 숫자 val만 합성해 탐지·입력 보정·필터 조정 |
| 다중 숫자 판독 | test · `final` | 단일 숫자 test만 합성해 전체 판독 최종 평가 |

두 번째 단계에서는 기존 CNN을 재학습하지 않으며 다중 숫자 train은 없다. 두 단계의 val은 같은 원본 풀을 사용하고 test도 같은 공식 test 풀을 사용한다. 다중 숫자 val·test끼리는 원본이 겹치지 않는다.

## 저장 경로

| 경로 | 내용 |
|---|---|
| `data/MNIST/raw/` | 공식 MNIST train 60,000장·test 10,000장 |
| `data/mnist_scenes/tuning/` | 조정용 합성셋·정답·검사 결과 |
| `data/mnist_scenes/final/` | 해상도 확정 후 생성할 최종 평가셋 |
| `data/mnist_scenes/archive/tuning_100_per_count/` | 초기 조정용 1,640장·기존 원본 분할 기록 |

## 생성 규칙

- **조정용:** 학습 코드의 seed 42 분할에서 validation 5,000장만 사용. 장면 seed 42.
- **최종용:** 공식 test 10,000장 사용. 장면 seed 43. 조정에 사용하지 않음.
- **분할 표기:** 메타데이터의 `source_split: train`은 공식 train 60,000장 중 validation 5,000장을 골랐다는 뜻이다. 조정용에 학습용 55,000장은 사용하지 않는다.
- **배분:** 1~16개 그룹별로 숫자 종류·가능한 줄 수를 최대한 균등 배분. 각 줄 최소 1개.
- **원본 선택:** 숫자 종류별 비복원 순환 추출. 반복 원본을 독립 표본으로 간주하지 않음.
- **영상:** 기본 640×480, 흰 배경·검은 회색조 숫자. MNIST 28×28 이미지를 24~28픽셀로 크기 변경.
- **배치:** 최대 4줄, 같은 줄의 이미지 세로 위치 ±2픽셀. 획 상자 기준 가로 ≥8·줄 사이 ≥16·가장자리 ≥16픽셀.
- **정답:** 크기 변경 후 밝은 획 ≥128의 최소 상자. `bbox=[x0,y0,x1,y1]`, 오른쪽·아래 끝 제외.
- **범위:** 추가 회전·잡음·흐림·잘림·잡티·기호·겹침 없음. 학습용 데이터가 아닌 판독 평가용.

| 용도 | 정상 장면 | 빈 장면 | 초과 입력 | 합계 |
|---|---:|---:|---:|---:|
| 조정용 | 개수별 1,000장, 16,000장 | 20장 | 17·20개 각 100장 | 16,220장 |
| 최종용 | 개수별 1,000장, 16,000장 | 100장 | 17·20개 각 10장 | 16,120장 |

조정용 정상 장면은 초기본 대비 10배다. 그룹별 숫자 종류·줄 수를 균등 배분하고, 검사 결과에 원본 사용 수·크기·화면 4×4 구역별 배치를 기록한다. 빈 장면은 동일한 흰 화면이므로 수량을 그대로 유지한다.

**현재 조정용 16,220장·숫자 139,700개 생성·무결성 검사 PASS.** 모든 정상 그룹이 숫자 0~9·크기 24~28픽셀·화면 16개 구역을 포함한다. 숫자 1개 그룹도 원본 1,000장·종류별 100장으로 늘었다. 판독 정확도는 아직 측정하지 않았다.

원본 손글씨는 validation 5,000장으로 제한된다. 장면 수 증가는 배치·크기·조합을 보강하며, 반복된 원본은 독립 표본이 아니다. 최종용은 해상도 확정 후 생성한다.

## 실행

프로젝트 Python 환경에서 실행한다.
아래 `.venv` 명령은 프로젝트 환경 구성 후 사용한다. 이번 생성 환경의 실제 버전은 `metadata.json`에 기록되어 있다.

```powershell
# 조정용 생성: 원본이 없으면 data/MNIST/에 다운로드
.\.venv\Scripts\python.exe .\python\generate_scenes.py --split tuning

# 분할·원본·픽셀·정답 상자·배분·간격·해시 검사
.\.venv\Scripts\python.exe .\python\verify_scenes.py
```

기존 출력 폴더는 덮어쓰지 않는다. 별도 실험은 `--output-dir`로 새 경로를 지정한다. 소규모 확인은 `--scenes-per-count`, `--blank-scenes`, `--overflow-scenes`로 수량을 줄일 수 있다.

확대본은 초기본의 `source_indices.json`과 원본 IDX를 사용해 동일한 validation 분할을 유지했다. PyTorch 없이 재생성할 때는 다음처럼 원본 목록과 새 출력 경로를 지정한다.

```powershell
python .\python\generate_scenes.py --split tuning --source-manifest .\data\mnist_scenes\archive\tuning_100_per_count\source_indices.json --output-dir .\data\mnist_scenes\tuning_new
```

최종셋은 해상도 확정 후 `--split final --width <너비> --height <높이>`로 생성하고 고정한다. 기본 640×480은 잠정값이다.

## 결과 파일

| 파일 | 내용 |
|---|---|
| `images/` | 정상·빈 장면·초과 입력 PNG |
| `manifest.jsonl` | 장면별 정답·좌표·읽기 순서·원본 ID·시드·이미지 해시 |
| `source_indices.json` | 허용된 MNIST 원본 ID와 분할 정보 |
| `metadata.json` | 다중 숫자 작업·val/test 역할·생성 설정·배분·버전·완료 상태·해시 |
| `preview.png` | 1·4·8·16개 장면과 정답 상자 미리보기 |
| `verification.json` | 무결성 검사·그룹별 원본/크기/위치 분포. 인식 정확도 측정 결과는 아님 |

숫자 탐지 프로그램에는 장면 이미지만 제공한다. 정답 위치는 채점기에만 전달한다.

검사기는 NumPy·Pillow로 원본 IDX와 장면을 비교한다. PyTorch를 사용할 수 있으면 validation 분할도 다시 계산한다. 현재 검사에서는 저장된 원본 ID 목록과 해시를 확인했으며, 분할 재계산 여부는 `verification.json`의 `split_recomputed`에 기록한다.
