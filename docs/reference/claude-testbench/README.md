최신 참조는 [testbench_v3.html](testbench_v3.html)이다. 비공개 공유 링크 대신 로컬 HTML을 기준으로 확인한다.

| 파일 | 용도 |

## 검토 결과 · 2026-10-19

**설계 참조 초안으로 사용 가능.** 기존 모델을 유지하고 전처리·평가 이식을 먼저 진행한다.

- argmax의 float 예측 보장 문구 수정, 동점은 작은 숫자 우선으로 통일.
- 재양자화 곱의 전체 폭·DSP 수 미정·bias 포함 범위 검증 명시.
- 층 전환은 후처리·메모리 쓰기 완료 뒤, batch done은 마지막 출력 저장 뒤 발생하도록 명시.
- 입력 버퍼 반납은 마지막 실제 읽기 뒤, READY는 crop 쓰기 완료 뒤 전달.

## 직접 확인한 내용

- 가중치 8개 텐서·26,698개 값이 `models/mnist_float_v1/best.pt`와 바이트 단위로 일치.
- 이전 참조와 DATA·CNN·숫자 분리·28×28 보정 코드 동일. 내장 200개 샘플 예측 모두 일치, logits 최대 절대 차이 약 `8.11e-6`.
- script 문법·SVG XML 파싱 통과. 숨김 Chrome에서 세 탭 전환·구조도 카드 선택·예시 10개 후보·빈 입력 0개 후보 확인.
- ROM `3,353×64b`, MAC `38,480 cycle/crop`, bias 제외 누산 폭 `20/23/26/21b` 재계산 일치. 100 MHz 가정의 `0.3848ms/crop`은 MAC 계산만의 이상값.

## 구현 방향

**적응형 이진화 → CCL(8방향 연결) → 획 병합·후보 필터 → 줄 정렬 → 28×28 보정 → 후보별 CNN 1회.**

| 구분 | 초안 |
|---|---|
| ARM | 전처리·후보 정리·crop·정렬·표시 |
| PL | P=8 공유 MAC으로 Conv·FC 재사용, 32비트 누산 |
| 메모리·통신 | BRAM·입력 이중 버퍼, AXI-Lite 제어·AXI BRAM 데이터 |
| 입력 보정 | 종횡비 유지·긴 변 20픽셀·28×28 여백·무게중심 정렬 |

브라우저는 float 소프트웨어이고 RTL은 미구현이다. INT8 정확도·누산 범위·재양자화 처리량·BRAM 지연·버퍼 제어·100 MHz timing·자원·보드 시간은 검증 전이다. busy 중 clear 처리와 ARM 쓰기 가시성·메모리 순서도 구현 시 확정한다.

## 이식 시 보완

- **crop:** 원본은 이진 마스크·획 보정 사용. 계획의 회색조 crop을 기본으로 성능 비교.
- **초과:** 원본은 면적순 선택 후 정렬. 계획대로 읽기 순서 앞 16개를 선택하고 초과 표시.
- **Otsu:** 순수 흑백 입력에서 검은 획을 놓치는 경계값 오류 수정. 기본 적응형 모드와는 별개.
- **채점:** 팽창·여백 영역과 원본 획 상자 구분. 기존 모델이 맞힌 큰 예시 대신 독립된 validation 합성셋으로 조정.

붙은 숫자·잡티·끊긴 획은 분리·오분류 오류가 날 수 있다. 낮은 softmax 표시가 숫자 아님 판정을 뜻하지 않는다. UI의 후보 상한은 기본 16·최대 64지만 보드 범위는 16개다.

다음 작업과 평가 기준은 [프로젝트 계획](../../계획.md)을 따른다. 새 참조는 검사 후 최신 HTML·이 문서·검사 기록을 함께 갱신하고 구버전을 정리한다.
