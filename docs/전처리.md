# 다중 숫자 전처리

- **구현:** [preprocess.py](../python/preprocess.py).
- **범위:** 위치 탐지·획 병합·필터·줄 정렬·회색조 28×28 입력 생성.
- **출력:** float32, `[N, 1, 28, 28]`, 0~1, 검은 배경·밝은 숫자.
- **분류:** CNN 추론·인식률 평가는 다음 단계. 정답 위치는 전처리에 제공하지 않음.

## 처리 순서

1) 적응형 이진화로 글씨 마스크 생성. 원본 회색조는 별도 유지.
2) 병합용 마스크 1픽셀 팽창 → 8방향 CCL → 끊긴 획 병합.
3) 크기·비율·화면 경계 필터 적용.
4) 모든 후보를 위→아래, 줄 안에서는 왼쪽→오른쪽으로 정렬.
5) 앞 16개 선택. 나머지는 `excess`, 초과 여부는 `overflow`로 반환.
6) 후보별 원본 회색조 crop → 긴 변 20픽셀 → 28×28 여백·무게중심 정렬.

- 기본값: 적응형 계수 0.2, 최소 높이 12, 획 병합 사용.
- Otsu는 선택 옵션. 임계값 0에서도 검은 획을 포함하도록 경계값 수정.
- 회색조 crop에서는 다른 덩어리를 제거하고 해당 후보의 밝기 값 유지.
- `--crop-mode mask`로 이진 마스크 crop과 비교 가능. 원본의 획 굵기 보정은 기본 적용하지 않음.
- CCL은 NumPy로 행의 연속 구간을 찾고 union-find로 연결. Torch·OpenCV·SciPy 불필요.

## 상자 구분

| 필드 | 의미 |
|---|---|
| `bbox` | 팽창 전 검출 마스크의 획 상자 |
| `component_bbox` | 병합용 팽창 마스크의 상자 |
| `crop_bbox` | 원본 회색조를 가져올 영역, 기본 여백 2픽셀 |

- 좌표는 `[x0, y0, x1, y1]`, 오른쪽·아래 끝 제외.
- 검출 상자는 정답 상자와 다를 수 있음. 정답의 밝은 획 ≥128 기준은 유지.

## 실행

NumPy·Pillow가 설치된 Python에서 실행. 기존 출력 폴더는 덮어쓰지 않음.

```powershell
python python/preprocess.py data/mnist_scenes/tuning/images/n16/scene_0000.png --output-dir build/preprocessing/example_next
```

- **결과:** `result.json`, `inputs.npy`, `mask.png`, `overlay.png`, `crops.png`.
- **설정:** `--binarization otsu`, `--no-merge`, `--min-height`, `--sensitivity`.
- **검은 배경 입력:** `--background black`으로 명시. 자동 반전 판단은 하지 않음.
