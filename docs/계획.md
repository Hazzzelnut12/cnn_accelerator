# 프로젝트 계획

## 1. 프로젝트 정의

- **목표:** 카메라 한 장면의 손글씨 숫자 **1~16개·최대 4줄** 인식.
- **대상:** Libertron AI Starter Kit, Zynq-7020. CNN은 **Verilog 직접 구현**.
- **범위:** 서로 떨어진 숫자. 위→아래, 줄 안에서는 왼쪽→오른쪽으로 출력.
- **일정:** 2026년 11월 중순 목표. 공식 마감·평가표 미정.

## 2. 계획 수립 및 의도

**PC에서 다중 숫자 판독 확인 → 정수화 → Verilog 구현 → 보드 검증·카메라 시연.**

현재 모델부터 검증하고, 비트 폭·병렬도·메모리 구조는 구현하면서 결정한다.

### 평가 기준

최종 판정은 **보드 전체 판독 결과**.

| 항목 | 기준 |
|---|---|
| 인식률 | 정확히 찾고 분류한 숫자 ÷ 정답 숫자, **98% 이상** |
| 추가 검출률 | 정답과 대응되지 않은 출력 ÷ 정답 숫자, **1% 이하** |
| 적용 범위 | **전체 합산과 1~16개 그룹 각각** 통과 |
| 정수화 | float 대비 손실 **0.3%p 이내**. 현재 기준 **98.74% 이상** |
| 계산 일치 | 시뮬레이션은 층별 정수값, 보드 CNN은 MNIST test 10,000장의 점수 10개 일치 |
| 전체 판독 일치 | 보드와 PC 정수 판독의 숫자별 검출·인식 결과 일치 |
| 속도 | 숫자 16개 장면 **P95 100ms 이하** |
| 빈 장면 | 최종 100장에서 **추가 검출 0개** |

- CNN 단독 정확도·숫자 종류별·줄 수별 성능은 별도 기록.
- **ARM 비교는 필수 보고**, 최소 가속 배율은 없음.
- 줄 정렬은 기능 확인만 수행. 실제 카메라는 정량평가 없이 시연.

### 평가 데이터·입력

| 용도 | 원본 | 합성 장면 수 | 시드 |
|---|---|---:|---:|
| 조정용 | validation 5,000장 | 개수별 100장, **1,600장** | 42 |
| 최종용 | test 10,000장 | 개수별 1,000장, **16,000장** | 43 |

- **배분:** 0~9와 가능한 줄 수를 균등 배분. 줄마다 최소 1개, 줄별 개수는 무작위 분할.
- **재사용:** 같은 숫자 종류 안에서 비복원 순환 추출. 반복 원본을 독립 표본으로 간주하지 않음.
- **고정:** 조정용·최종용 원본 분리. 최종셋은 조정에 사용하지 않고, 시드·원본 ID·정답·위치 저장.
- **예외:** 빈 장면 조정용 20장·최종용 100장, 숫자 17·20개 장면 각 10장 추가.
- **영상:** 640×480 잠정, 숫자 이미지 24~28픽셀, 같은 줄의 세로 위치 ±2픽셀.
- **간격:** 획 상자 기준 가로 ≥8·줄 사이 ≥16·가장자리 ≥16픽셀. 배치 불가 시 재추출.
- **조건:** 흰 배경·검은 숫자. 추가 회전·잡음·흐림·잘림·잡티·기호·겹침 제외. 합성셋으로 재학습하지 않음.

### 전처리·채점

- **CNN 입력:** 검은 배경·밝은 숫자의 회색조 28×28, 픽셀÷255.
  - 흰 배경 영상만 `255-gray`로 반전. CNN 입력은 이진화하지 않음.
  - 정답 상자는 밝은 숫자 기준 **화소값 ≥128인 획**을 감싸는 최소 사각형.
- **대응:** 여백 추가 전 검출 상자와 **일반 사각형 IoU ≥0.5**, 위치로 일대일 연결.
  - 대응 수 최대 → IoU 합 최대 → 동률은 ID 순서. 숫자 라벨은 대응 선택에 사용하지 않음.
  - PC에서 채점하며 인식 프로그램에는 정답 위치를 제공하지 않음.
- **오류:** 누락·오분류는 인식 실패, 남는 출력은 추가 검출.
  - 분할·중복은 최대 하나만 대응. 병합도 최대 정답 하나만 대응.
- **초과:** 읽기 순서 **앞 16개 출력 + 용량 초과 표시**.
  - 정답 17·20개는 기능 검사만 수행. 정답 1~16개의 초과 발생은 정상 평가에서 제외하지 않음.
- 빈 장면은 분모가 0이므로 주 지표에 합산하지 않음.

### 측정·시연

- **시간:** DDR 프레임 준비 완료 → 전처리·전송·CNN·정렬·결과 반환.
  - SD 읽기·촬영 대기·화면 갱신은 별도. ARM global timer로 구간별 측정.
- **반복:** 1·4·8·16개별 준비 실행 10회 후 서로 다른 최종 장면 1,000회 측정.
  - 평균·P95·최대, 장면/s·숫자/s·CNN 단독 처리량 기록. 카메라 경로는 별도 측정.
- **ARM 비교:** 동일 정수 모델·입력, C/C++ 1코어·`-O3`·자동 NEON 허용.
  - 출력 일치 확인. CNN 구간과 전체 판독 비교, FPGA 전송·제어 비용 포함.
  - 실제 클록·컴파일 옵션 기록. 수작업 SIMD·어셈블리 최적화는 요구하지 않음.
- **시연:** 흰 종이·검은 펜·고정 조명·정면 촬영. 숫자 크기를 합성셋 범위에 맞춤.
  - 검출 상자·인식값과 줄바꿈한 문자열 표시. 1·4·8·16개·빈 장면·초과 입력 및 결과 갱신 확인.

**수령 후 확정:** 카메라·표시 장치·최종 해상도·촬영 거리·펜 굵기.
