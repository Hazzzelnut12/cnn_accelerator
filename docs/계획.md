# 프로젝트 계획

## 1. 프로젝트 정의
- **목표:** 카메라 한 장면의 손글씨 숫자 **1~16개·최대 4줄** 인식.
- **대상:** Libertron AI Starter Kit, Zynq-7020. CNN은 **Verilog 직접 구현**.
- **범위:** 서로 떨어진 숫자. 위→아래, 줄 안에서는 왼쪽→오른쪽으로 출력.

## 2. 계획 수립 및 의도
**PC에서 다중 숫자 판독 확인 → 정수화 → Verilog 구현 → 보드 검증·카메라 시연.**
- 현재 모델부터 검증
- 비트 폭·병렬도·메모리 구조는 구현하면서 결정.

### 다중 숫자 판독 구현 방향
[Claude 테스트벤치 v3](reference/claude-testbench/README.md)바탕
**위치 탐지 → 후보 정리·줄 정렬 → 28×28 보정 → 기존 CNN 반복 실행**.

| 구분 | 구현 방향 |
|---|---|
| 위치 탐지 · ARM | 적응형 이진화 → CCL(8방향 연결) → 끊긴 획 병합·크기·비율 필터 |
| 입력 보정 · ARM | 후보별 crop → 종횡비 유지·긴 변 20픽셀 → 28×28 여백·무게중심 정렬 |
| 숫자 분류 · PL | CNN 회로 하나로 후보마다 1회, 최대 16회. Conv·FC는 같은 MAC 배열 재사용 |
| 메모리 · 초안 | 가중치·중간 결과는 BRAM, 입력은 이중 버퍼. Conv·ReLU·Pool 결합으로 저장량 축소 |
| 통신 · 초안 | AXI-Lite로 시작·개수·상태 제어, AXI BRAM으로 crop 전달. 결과는 묶어서 반환 |
- **모델 유지:** `mnist_float_v1` 사용. ARM은 분기·정렬, PL은 반복 곱셈·누산 담당.
- **적용 한계:** 분리된 숫자가 대상. 붙은 숫자는 분리하지 못하며, 잡티도 숫자로 분류될 수 있음. 원본은 화면 경계 후보 제외.
- **이식 보완:** 회색조 crop을 기본으로 마스크·획 보정과 비교. Otsu 경계값 수정, 읽기 순서 앞 16개 선택, 채점 상자와 팽창·여백 구분.
- **검증 후 확정:** INT8·병렬도 P=8은 초안. 누산은 32비트 기준으로 범위 확인 후 축소 여부 결정. 전체 판독률·ARM 전처리 포함 시간은 미측정.

### 평가 기준
최종 판정: **보드 전체 판독 결과**.

| 항목 | 기준 |
|---|---|
| 인식률 | 정확히 찾고 분류한 숫자 ÷ 정답 숫자, **98% 이상** |
| 추가 검출률 | 정답과 대응되지 않은 출력 ÷ 정답 숫자, **1% 이하** |
| 적용 범위 | **전체 합산과 1~16개 그룹 각각** 통과 |
| CNN 단독 정수화 | 단일 숫자 test에서 float 대비 손실 **0.3%p 이내**. 현재 기준 **98.74% 이상** |
| 계산 일치 | 시뮬레이션은 층별 정수값, 보드 CNN은 MNIST test 10,000장의 점수 10개 일치 |
| 전체 판독 일치 | 보드와 PC 정수 판독의 숫자별 검출·인식 결과 일치 |
| 속도 | 숫자 16개 장면 **P95 100ms 이하** |
| 빈 장면 | 최종 100장에서 **추가 검출 0개** |

- CNN 단독 정확도·숫자 종류별·줄 수별 성능은 별도 기록.
- **ARM 비교는 필수 보고**, 최소 가속 배율은 없음.
- 줄 정렬은 기능 확인만 수행. 실제 카메라는 정량평가 없이 시연.

### 평가 데이터·입력

**1단계 · 단일 숫자 CNN 학습·평가**

| 구분 | 원본 수 | 분할 시드 | 용도 |
|---|---:|---:|---|
| train | 55,000장 | 42 | CNN 가중치 학습 |
| val | 5,000장 | 42 | 학습 설정·가중치 선택 |
| test | 10,000장 | 해당 없음 | CNN 단독 정확도 평가, 현재 **99.04%** |

공식 MNIST train 60,000장을 seed 42로 한 번 분할해 train·val 구성. 공식 test는 제공된 구성을 그대로 사용. 학습 시드도 42로 가중치 초기화·입력 순서·증강에 사용.

**2단계 · 다중 숫자 판독 조정·평가**

| 구분 | 원본 | 정상 합성 장면 수 | 장면 시드 |
|---|---|---:|---:|
| val · 조정용 | 1단계 val 5,000장 | 개수별 1,000장, **16,000장** | 42 |
| test · 최종용 | 1단계 test 10,000장 | 개수별 1,000장, **16,000장** | 43 |

- **시드 구분:** 위의 분할 시드는 원본의 소속을 결정하고, 장면 시드는 원본 추출·크기·배치를 재현. 장면 시드 43으로 원본을 다시 분할하는 것은 아님.
- **역할:** 다중 숫자 train은 만들지 않음. 기존 CNN을 유지하고 val로 위치 탐지·입력 보정·필터를 조정, test로 전체 판독 평가. CNN 단독 정확도와 구분해 보고.
- **휴리스틱 적용:** 위치 탐지·후보 정리 규칙을 조정. 채점은 정답 위치·라벨과 IoU·인식률 기준으로 수행.
- **현재:** 조정용 정상 16,000장 + 예외 220장, **16,220장 생성·무결성 검사 완료**. 초기본 대비 정상 장면 10배. 최종용은 미생성. [저장 경로·생성 방법](합성데이터.md)
- **배분:** 0~9와 가능한 줄 수를 균등 배분. 줄마다 최소 1개, 줄별 개수는 무작위 분할.
- **재사용:** 같은 숫자 종류 안에서 비복원 순환 추출. 반복 원본을 독립 표본으로 간주하지 않음.
- **고정:** 조정용·최종용 원본 분리. 최종셋은 조정에 사용하지 않고, 시드·원본 ID·정답·위치 저장.
- **예외:** 빈 장면 조정용 20장·최종용 100장. 숫자 17·20개 장면은 조정용 각 100장·최종용 각 10장 추가.
- **영상:** 640×480 잠정, 숫자 이미지 24~28픽셀, 같은 줄의 세로 위치 ±2픽셀.
- **간격:** 획 상자 기준 가로 ≥8·줄 사이 ≥16·가장자리 ≥16픽셀. 배치 불가 시 재추출.
- **조건:** 흰 배경·검은 숫자. 추가 회전·잡음·흐림·잘림·잡티·기호·겹침 제외. 합성셋으로 재학습하지 않음.

### 전처리·채점

- **CNN 입력:** 검은 배경·밝은 숫자의 회색조 28×28, 픽셀÷255.
  - 흰 배경 영상만 `255-gray`로 반전. CNN 입력은 이진화하지 않음.
  - 정답 상자는 밝은 숫자 기준 **화소값 ≥128인 획**을 감싸는 최소 사각형.
- **대응:** 여백 추가 전 검출 상자와 **일반 사각형 IoU ≥0.5**, 위치로 일대일 연결.
  - 대응 수 최대 → IoU 합 최대 → 동률은 ID 순서. 숫자 라벨은 대응 선택에 사용하지 않음.
  - PC에서 채점하며 인식 프로그램에는 정답 위치를 제공하지 않음.
- **오류:** 누락·오분류는 인식 실패, 남는 출력은 추가 검출.
  - 분할·중복은 최대 하나만 대응. 병합도 최대 정답 하나만 대응.
- **초과:** 읽기 순서 **앞 16개 출력 + 용량 초과 표시**.
  - 정답 17·20개는 기능 검사만 수행. 정답 1~16개의 초과 발생은 정상 평가에서 제외하지 않음.
- 빈 장면은 분모가 0이므로 주 지표에 합산하지 않음.

### 측정·시연

- **시간:** DDR 프레임 준비 완료 → 전처리·전송·CNN·정렬·결과 반환.
  - SD 읽기·촬영 대기·화면 갱신은 별도. ARM global timer로 구간별 측정.
- **반복:** 1·4·8·16개별 준비 실행 10회 후 서로 다른 최종 장면 1,000회 측정.
  - 평균·P95·최대, 장면/s·숫자/s·CNN 단독 처리량 기록. 카메라 경로는 별도 측정.
- **ARM 비교:** 동일 정수 모델·입력, C/C++ 1코어·`-O3`·자동 NEON 허용.
  - 출력 일치 확인. CNN 구간과 전체 판독 비교, FPGA 전송·제어 비용 포함.
  - 실제 클록·컴파일 옵션 기록. 수작업 SIMD·어셈블리 최적화는 요구하지 않음.
- **시연:** 흰 종이·검은 펜·고정 조명·정면 촬영. 숫자 크기를 합성셋 범위에 맞춤.
  - 검출 상자·인식값과 줄바꿈한 문자열 표시. 1·4·8·16개·빈 장면·초과 입력 및 결과 갱신 확인.

**수령 후 확정:** 카메라·표시 장치·최종 해상도·촬영 거리·펜 굵기.
조사할 항목과 확보할 파일은 [보드 조사표](보드조사.md)에 정리.

### A · 수행

- 원본 3개를 `docs/reference/claude-testbench/`에 복사하고 SHA-256 일치 확인.
- CCL 기반 위치 탐지와 후보별 CNN 호출 확인. HTML의 가중치 26,698개가 `best.pt`와 바이트 단위로 일치.
- Node.js에서 내장 샘플 200개 예측이 기록과 모두 일치. logits 최대 절대 차이 약 `8.11e-6`.
- 이진 마스크 crop·면적순 초과 선택·시연 예시 조건의 차이를 확인하고 Otsu의 흑백 입력 경계값 오류 재현.
- v3의 argmax·재양자화·완료 조건 보완 확인. 브라우저 동작 재검사 후 최신 참조·검사 기록으로 통합하고 구버전 정리.

### R · 결과

- **기존 모델을 유지하고 전처리·평가 이식을 먼저 진행.** 지금 단계에서 재학습이나 새 탐지 모델로의 교체는 필요하지 않음.
- [검토 내용·다음 작업](reference/claude-testbench/README.md)과 [검사 결과](reference/claude-testbench/verification.json) 보관.
- 전체 MNIST·계획의 합성 장면·실사진·ARM/PL 성능을 이번 검토에서 측정한 것은 아님.

## 5. 조정용 합성셋 생성 · 2026-10-19

### S · 상황

### T · 목표

### R · 결과

## 6. 데이터 단계 구분·조정용 보강 · 2026-10-19

### S · 상황

### T · 목표
